## Orphaned-gate state (the bug Phase 0 fixes)

`tests/render/test_visual_fidelity_gate.py` was the render gate designed to
catch the brand-heading and button color defects. It was never tracked in git
and therefore never ran on CI. The entire `tests/render/` directory was at
`?? tests/render/` in git status.

Phase 0 fixes this by:
1. Creating new harness modules (`capture_plan.py`, `harness_gate.py`,
   `contact_sheet.py`, `capture_harness.py`) with TDD RED-then-GREEN.
2. `git add tests/render/` so all harness files are tracked.
3. The new harness tests are offline-safe (self-skip when no references).
4. The full before-capture tree is generated by `capture_harness.py` against prod.
