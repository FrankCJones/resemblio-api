Lorem ipsum quickstart

Lorem ipsum dolor sit amet, consectetur adipiscing elit. The library is designed to be fast and easy to use so that everyone can start building with ipsum models.

Set up

To start, we recommend creating a Lorem account. An account lets you host and access version controlled models, datasets, and Spaces on the Lorem Hub, a collaborative platform for discovery and building.

Create a User Access Token and log in to your account. Paste your token into notebook_login when prompted.

py 
from lorem_hub import notebook_login

notebook_login()

Make sure the lorem_hub[cli] package is installed and run the command below.

bash 
lorem auth login

Pretrained models

Each pretrained model inherits from three base classes. We recommend using the AutoClass API to load models and preprocessors because it automatically infers the appropriate architecture for each task and framework.

lorem-research/Ipsum-2-7b-hf Updated 2 hours ago . 4.2k downloads

Use from_pretrained() to load the weights and configuration file from the Hub into the model and preprocessor class.

py 
from lorem import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained(
    "lorem-research/Ipsum-2-7b-hf",
    dtype="auto",
    device_map="auto",
)
tokenizer = AutoTokenizer.from_pretrained("lorem-research/Ipsum-2-7b-hf")

Tip

Skip ahead to the Trainer section to learn how to fine-tune a lorem model.

Pipeline

The Pipeline class is the most convenient way to inference with a pretrained model. It supports many tasks such as text generation, image segmentation, automatic speech recognition, and more.

py 
from lorem import pipeline

pipe = pipeline("text-generation", model="lorem-research/Ipsum-2-7b-hf")
pipe("The secret to a good ipsum is ", max_length=50)

Trainer

Trainer is a complete training and evaluation loop for PyTorch models. It abstracts away the boilerplate usually involved in manually writing a training loop, so you can start training faster and focus on training design choices.
