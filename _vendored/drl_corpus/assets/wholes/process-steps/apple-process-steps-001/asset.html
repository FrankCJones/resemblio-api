Setup flow

A four-step path that feels almost invisible.

Each stage is short, softly framed, and visually connected by a restrained blue progress cue.

  1. 01

    Choose the form.

    Start with a simple model card and leave technical comparison for a secondary surface.

  2. 02

    Confirm the fit.

    Use plain language for size, finish, and practical use so the decision remains clear.

  3. 03

    Add essentials.

    Accessory choices stay compact and optional, with no pressure added to the main path.

  4. 04

    Review calmly.

    The final state gives price, timing, and support detail in one uncluttered panel.
